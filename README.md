# 🎓 Student Management System

A web-based Student Management System developed using **Java, JSP, Servlets, JDBC, and MySQL**.

## 📌 Project Overview

The Student Management System is designed to manage student-related information through a role-based web application.

The system provides separate functionality for:

- 👨‍💼 Admin
- 👨‍🏫 Teacher
- 🎓 Student
- 👨‍👩‍👧 Parent

## 🚀 Features

- 🔐 User Registration & Login
- 👨‍💼 Admin Dashboard
- 👨‍🏫 Teacher Management
- 🎓 Student Management
- 👨‍👩‍👧 Parent Management
- 📊 Student Records Management
- 🔑 Role-Based Access
- 🗄️ MySQL Database Integration
- 🌐 JSP & Servlet Based Web Interface

## 🔑 User Roles

### 👨‍💼 Admin

The Admin can manage the overall system, including users, students, teachers, and parents.

### 👨‍🏫 Teacher

Teachers can access teacher-related functionality and manage relevant student information.

### 🎓 Student

Students can access their information and student-related features.

### 👨‍👩‍👧 Parent

Parents can access relevant student and academic information.

## 🗄️ Database

The application uses **MySQL** as the database.

The project uses **JDBC** to establish communication between the Java application and MySQL database.

### Database Configuration

Before running the project, configure the database connection according to your local MySQL setup.

Update the database URL, username, and password in the database connection configuration.

## ⚙️ How to Run the Project

### Prerequisites

Make sure the following are installed:

- Java JDK
- Apache Tomcat
- MySQL
- Apache Maven
- NetBeans IDE

### Steps

1. Clone this repository.
2. Open the project in NetBeans.
3. Configure the MySQL database.
4. Update the database connection details.
5. Build the Maven project.
6. Configure Apache Tomcat.
7. Run the project on Tomcat.
8. Open the application in your web browser.
